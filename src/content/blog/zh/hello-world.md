## 为什么做这个站

我是一名普通的 C++ 工程师。

过去几年，我的工作内容主要是在 Linux 上写高性能服务、调试 CUDA 内核、把模型塞进嵌入式板子。说实话，这些工作给了我扎实的技术底子，但也让我慢慢意识到一件事——**光靠上班，已经满足不了我对"成长"和"创造"的渴望了**。

AI 工具爆发之后，这种感觉更强烈。

以前需要花一周写的工具脚本，现在用 Claude Code 一晚上就能搞定；以前调一个诡异的内存泄漏要两三天，现在让 AI 帮我分析调用栈 + 给我修复方案，半小时就解决。**生产力被放大了，但同时我也开始问自己：那我应该把放大后的时间，用在哪里？**

答案就是这个网站。

## 这个站会写什么

我会围绕三个方向持续输出：

### 1. AI Infra / 嵌入式 / 高性能 C++ 实战（主战场）

这是我的本职工作，也是我最有积累的领域。我会写：
- vLLM、TensorRT-LLM 等推理引擎的源码剖析
- CUDA 优化的实战案例（带 Profiling 数据）
- C++ 协程、内存池、零拷贝这些"老话题"的现代写法
- 嵌入式 AI 部署（ONNX Runtime、Tengine、RK3588）

### 2. AI 时代程序员的工作流（30%）

我会记录自己怎么用 AI 工具改造开发流程：
- 我如何用 Claude Code + Cursor 重构一个 10 万行的老项目
- 我的 `.cursorrules` / `CLAUDE.md` 模板分享
- AI 工具在底层 C++ 项目中的边界（哪些它做不好、为什么）

### 3. 程序员成长与认知（20%）

更广义的思考，面向所有同行：
- 大学生如何入门 C++/系统编程
- 程序员如何搭建"代码之外的第二收入"
- 我对远程工作、独立开发、技术布道的看法

## 为什么不做公众号 / CSDN

我也想过只发在公众号或者知乎上。但最终还是选择做一个自己的网站，原因很简单：

> **个人网站是"数字资产"，平台账号是"租来的流量"**。

公众号改一次规则可能让你掉一半粉丝，CSDN 哪天挂了你的内容就没了。但你自己的域名、自己的内容，永远在那里——**10 年后、20 年后，依然可以通过 `buildbyliang.com` 访问到**。

而且双语的网站还能让我的内容被海外开发者看到，这是一个公众号永远做不到的事。

## 关于更新节奏

我的目标是 **每周一篇深度文**。

不水、不追热点、不复制粘贴。每篇文章都要回答一个真实的问题——要么是我踩过的坑，要么是我思考后的结论，要么是我拆解的源码。

**如果某周写不出值得发的东西，我就宁可不发。** 质量永远比数量重要。
